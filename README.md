# تطبيق مُذكِّر برو (Mudakkir Pro) - مشروع أندرويد الكامل (APK)

تطبيق أندرويد متكامل باللغة العربية لإدارة **اشتراكات العملاء والمواعيد والملاحظات الذكية** مع **نظام إشعارات فوري (AlarmManager + Heads-Up Notifications)** يعمل بدقة الثانية حتى في الخلفية أو بعد إعادة تشغيل الهاتف.

## أسرع طريقة لاستخراج ملف `APK` بدون تثبيت أي برامج (عبر GitHub Actions خلال دقيقتين)

1. أنشئ مستودعاً جديداً (Repository) على حسابك في **GitHub**.
2. فك الضغط عن هذا الملف المضغوط وارفع محتوياته بالكامل (بما فيها مجلد `.github/workflows/build-apk.yml` ومجلد `app/`) إلى المستودع.
3. ادخل إلى تبويب **Actions** في مستودعك، وستجد عملية البناء **Build Mudakkir Pro Android APK** تعمل تلقائياً.
4. فور انتهائها باللون الأخضر، اضغط عليها وحمّل ملف **`Mudakkir-Pro-Android-APK`** من قسم **Artifacts** لتثبيت ملف `.apk` مباشرةً على هاتفك!

## البناء المحلي عبر Android Studio

1. افتح برنامج **Android Studio** واختر **Open** ثم حدد مجلد المشروع.
2. من القائمة العلوية اختر **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
3. ستجد ملف الـ APK جاهزاً في المسار: `app/build/outputs/apk/debug/`.
